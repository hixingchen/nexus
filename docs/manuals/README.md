## 版本维护约定

- 手册按**界面/操作流程**建版本目录，不是每个应用版本都重写。
- 只改功能细节、界面和操作步骤没变：继续用当前手册，只在索引里注明适用版本范围。
- 大版本或界面/流程有明显变化：新建 `windows/vX.Y.Z/`，旧目录保留，方便用户对照旧界面。
- 截图放在对应版本目录的 `images/` 下，使用相对路径引用；演示数据不得包含真实项目/账号/密钥。
- `docs/issues/` 是本地问题记录目录，已加入 `.gitignore`，不随仓库提交。
